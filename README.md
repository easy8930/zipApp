# ZIP App

Windows 10/11 でローカル動作する ZIP 圧縮・解凍アプリです。通信や外部サービスは使いません。

## 起動

1. Python 3.12 以降を https://www.python.org/ からインストールします。インストーラーの Python Launcher と Tcl/Tk（通常は既定で有効）が必要です。
2. このリポジトリをダウンロード・展開します。
3. `start.bat` をダブルクリックします。または、このフォルダーで `py -3 app.py` を実行します。

外部 Python パッケージのインストールは不要です。現時点では単体の exe は同梱していません。

## 操作

- 「ファイルを追加」「フォルダーを追加」で項目を登録し、「選択した項目を ZIP に圧縮」で保存します。フォルダー構造と空フォルダーも保持します。
- 「ZIP を選んで解凍」で ZIP と保存先の親フォルダーを選びます。ZIP と同じ名前の新しいフォルダーに解凍します。既存フォルダーには上書きしません。
- 圧縮の保存ダイアログでは既存 ZIP の置き換えが可能です。選択した入力ファイルやフォルダー内部への保存はできません。
- 処理中も画面は応答し、失敗した場合は理由を表示します。

## 対応範囲

ZIP（保存・Deflate）の作成と Python 標準ライブラリが対応する ZIP の解凍。暗号化 ZIP、7z、RAR は未対応です。Windows で危険な名前、リンク、重複名を含む ZIP は拒否します。解凍上限は合計 10 GiB、10万項目です。古い ZIP の日本語名は作成元の文字コードによって文字化けする場合があります。

## 開発・検証

`python -m unittest discover -s tests -v`

圧縮・解凍処理は Linux でも検証できます。Windows の画面と起動バッチは Windows 上で別途確認が必要です。
